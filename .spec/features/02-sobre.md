## Conteúdo da seção

A seção deve apresentar:
- História do projeto
- Missão
- Visão
- Valores
- Importância da reutilização de livros

## Requisitos técnicos

- HTML + CSS + JS puro em um único arquivo
- Responsivo (mobile e desktop)
- Animações suaves de entrada ao rolar a página (scroll reveal)
- Cards ou blocos visuais para Missão, Visão e Valores
- Ícones via Font Awesome ou SVG inline
- Sem frameworks externos além de Google Fonts e Font Awesome
- Seção isolada, pronta para ser inserida em um site maior (usar <section id="sobre">)
